🚨 災害の種類別の行動ガイド

🏠 家の中にいるとき

・まずは頭を守る（机の下やクッションで保護）。
・揺れが収まるまで動かない（慌てて外に出ない）。
・火は揺れが収まってから消す。

🏢 エレベーター・街中

・エレベーターは全ての階を押して即降りる。
・街中ではブロック塀やガラス窓から離れる。

🌧️ 暴風・大雨のとき

・用水路、川、海には絶対に近づかない。
・地下道（アンダーパス）は水が溜まり危険なので避ける。
・明るいうちに早めに頑丈な建物へ避難する。

🌊 強い揺れ・津波警報のとき

・遠くではなく「より高い場所」を目指してすぐに逃げる。
・「ここまで来ないだろう」の自己判断は厳禁。
・一度逃げたら警報が解除されるまで絶対に戻らない。

🔥 火事が発生したとき

・「火事だ！」と大声で周囲に知らせる。
・煙を吸わないようハンカチ等で口を覆い、姿勢を低くして逃げる。
・一度外に逃げたら、荷物を取りに戻らない。

📱 スマホ標準の緊急SOS＆便利機能（1〜4）

※端末の種類やOSのバージョンによって画面の表示・操作方法が若干異なる場合があります。

1. ボタン連打で起動！「緊急SOS」
【どうなる？】 通報画面を素早く呼び出します。さらに事前設定しておくと、通報後に「あなたの現在地」がSMSで家族へ自動送信されます。

＜使い方・設定方法＞

iPhone 電源（サイド）ボタンを5回連打（または電源＋音量ボタン長押し）
・事前設定: 「設定」アプリ ➔ 「緊急SOS」 ➔ 「ヘルスケアで緊急連絡先を編集」から家族を追加
Android 電源ボタンを5回連打
・事前設定: 「設定」アプリ ➔ 「緊急情報とSOS」 ➔ 「緊急連絡先」から家族を追加
2. ロック画面から確認「メディカルID」
【どうなる？】 意識を失った時でも、救助者や警察がスマホのロックを解除せずに氏名・持病・血液型・家族の連絡先を確認できます。

＜設定方法＞

iPhone 「ヘルスケア」アプリを開く ➔ 右上プロフィールアイコン ➔ 「メディカルID」を登録
Android 「設定」アプリ ➔ 「緊急情報とSOS」 ➔ 「緊急情報（またはメディカル情報）」を登録
3. 家族でマップ確認「位置情報の常時共有」
【どうなる？】 被災時に連絡が取れなくても、お互いの現在地がマップ上にリアルタイム表示され、無事や居場所がひと目でわかります。

＜設定方法＞

iPhone（探すアプリ） 「探す」アプリ ➔ 「人を探す」 ➔ 「位置情報を共有」で家族を選択
共通（Googleマップ） Googleマップ ➔ 右上アイコン ➔ 「位置情報の共有」 ➔ 「無期限」で家族に共有
4. 3秒で居場所を通知「LINE位置情報送信」
【どうなる？】 パニックで文字が打てない時でも、たった3タップで現在地ピンを家族トークに送信できます。

＜操作方法（iPhone・Android共通）＞

  1. 家族のLINEトーク画面を開く
  2. 左下の 「＋」 マークをタップ
  3. 「位置情報」 を選び ➔ 「この位置を送信」 を押す（3秒で完了）
